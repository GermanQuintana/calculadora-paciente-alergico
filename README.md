# Calculadora de rentabilidad del paciente alérgico

Herramienta de página única (sin servidor) que compara, para un perro con dermatitis atópica, el coste para el tutor y el margen de la clínica de tratar solo con sintomáticos (Apoquel, Zenrelia, Numelvi, Cytopoint, ciclosporina) o con prueba de alergia e inmunoterapia.

- Abrir `index.html` o la página de GitHub Pages del repositorio.
- Los precios de ejemplo son de CV A Marosa; cada clínica puede editarlos en **Configuración**.
- Los datos introducidos se guardan solo en el navegador de cada persona. Para pasarlos a otro equipo o a un compañero: **Configuración → Exportar mis datos / Importar datos**.
